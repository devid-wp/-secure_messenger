# Состав версии 1.0

## Цель

Версия 1.0 — минимальный пригодный к использованию E2EE-мессенджер для текста,
личных и небольших групповых чатов с несколькими устройствами пользователя.
Конфиденциальность содержимого не должна зависеть от честности delivery-сервера.

## Клиенты и ограничения

- Поддерживаемый клиент: desktop-браузер с React.
- Поддерживаемые браузеры фиксируются перед релизом после WASM-прототипа.
- Один пользователь: до 5 активных устройств.
- Группа: от 2 до 100 пользователей и не более 500 устройств.
- Текст сообщения: UTF-8, максимум 16 KiB до шифрования.
- Ciphertext envelope: максимум 64 KiB.
- Offline-очередь на сервере: 30 дней.
- Локальная история ограничивается только хранилищем устройства.

## Входит в v1.0

### Учётная запись и устройства

- регистрация по уникальному логину и паролю;
- вход и управление серверной сессией;
- список собственных устройств;
- добавление устройства только с подтверждением уже доверенного устройства;
- отзыв потерянного устройства;
- отображение изменения набора устройств всем участникам затронутых чатов;
- QR-код и короткий safety code для ручной проверки контакта.

### Чаты

- DM между двумя пользователями;
- приватные группы;
- роли `owner`, `admin`, `member`;
- добавление и удаление участников;
- изменение зашифрованного названия группы;
- выход из группы;
- локальное скрытие чата.

### Сообщения

- только текст;
- отправка в offline;
- порядок по клиентскому порядковому номеру и серверному времени приёма;
- дедупликация повторной отправки;
- статусы `sending`, `sent`, `delivered`, `failed`;
- опциональное уведомление о прочтении как E2EE control message;
- локальное удаление сообщения или всей истории;
- локальный полнотекстовый поиск.

### Безопасность

- E2EE для текста, названий групп, read receipts и служебных событий приложения;
- TLS 1.3 для всего сетевого транспорта;
- forward secrecy и post-compromise security в пределах гарантий MLS;
- автоматическая смена эпохи при изменении состава устройств или участников;
- запрет plaintext, ключей и чувствительных payload в логах и telemetry.

## Не входит в v1.0

- вложения, изображения, голосовые сообщения;
- аудио- и видеозвонки;
- редактирование сообщения;
- удаление сообщения на чужих устройствах;
- реакции, ответы, треды и упоминания;
- публичные группы, каналы, боты и federation;
- серверный поиск и серверная модерация содержимого;
- plaintext preview в push-уведомлениях;
- облачная резервная копия истории или ключей;
- восстановление старой истории после потери всех устройств;
- key transparency log;
- сокрытие IP-адреса и полной социальной диаграммы от сервера;
- post-quantum ciphersuite.

## Поведение функций, отложенных после v1.0

Отложенная функция не должна требовать смены базовой E2EE-модели:

| Функция | Зафиксированный подход |
|---|---|
| Группы | Уже используют ту же MLS-модель, что DM |
| Поиск | Только локальный индекс plaintext |
| Вложения | Случайный file key; blob шифруется на клиенте, key передаётся внутри E2EE-сообщения |
| Уведомления | Push содержит только opaque event; preview создаёт клиент после расшифровки |
| Backup | Только opt-in клиентский encrypted export с отдельным recovery secret |
| Новое устройство | Получает только явно переданную историю; сервер не может расшифровать и экспортировать её |

## Критерии готовности v1.0

Релиз запрещён, пока не выполнены все условия:

1. E2EE-код изолирован от UI и network transport.
2. OpenMLS/WASM проходит interop-векторы и тесты минимум в двух браузерах.
3. Серверная БД не содержит plaintext сообщений, названий групп и read receipts.
4. Есть тесты добавления/отзыва устройства и смены MLS epoch.
5. Есть тесты replay, reorder, duplicate, offline delivery и повреждённого ciphertext.
6. Клиент показывает изменение safety code и состава устройств.
7. Выполнен независимый security review E2EE-обвязки.
8. Документация и модель угроз соответствуют фактическому сетевому протоколу.
